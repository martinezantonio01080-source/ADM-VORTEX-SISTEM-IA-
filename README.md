# Atmospheric & Climate AI (Gemini XPRIZE Project)

A real-time regional telemetry and climate analysis tool designed to fetch live meteorological data with built-in safety validation layers against thermal hallucinations.

## Features
- **Real-Time Regional Telemetry:** Search weather conditions by state/region and country code using the OpenWeatherMap API.
- **Strict Validation Layer:** Built-in safeguards to filter out erratic or illogical temperature readings.
- **Modern Glassmorphism UI:** Clean, responsive design optimized for seamless user experience.

## Tech Stack
- **HTML5 & CSS3:** Modern structure and styling with gradient aesthetics.
- **JavaScript (ES6+):** Asynchronous telemetry handling via `fetch` API.
- **OpenWeatherMap API:** Live meteorological data provider.
